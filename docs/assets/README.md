# Documentation Assets

This folder contains images and assets used in the documentation and README.

## Required Images

Please upload the following images to this folder to make the README screenshots work:

1.  `home.png` - Screenshot of the landing page.
2.  `dashboard.png` - Screenshot of the admin dashboard.
3.  `mobile.png` - Screenshot of the mobile view.
4.  `dark.png` - Screenshot of the dark mode view.

Recommended size: 1200x675 (16:9 aspect ratio).
